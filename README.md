# Site de Contagem de Calorias

Projeto desenvolvido com Django para auxiliar no controle de calorias e proteínas consumidas ao longo do dia.

## Funcionalidades

- Cadastro de refeições
- Controle de calorias por refeição
- Controle de proteínas por refeição
- Definição de metas diárias
- Dashboard com acompanhamento de consumo
- Integração com IA local para suporte inteligente (Ollama + Llama 3)

## Tecnologias Utilizadas

- Python
- Django
- HTML5
- CSS3
- Bootstrap
- SQLite
- Ollama (IA local)
- Llama 3 (modelo de linguagem)

## Como Executar o Projeto

### Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### Acesse a pasta

```bash
cd Site-de-contagem-de-calorias
```

### Crie o ambiente virtual

```bash
python -m venv venv
```

### Ative o ambiente virtual

Windows:

```bash
venv\Scripts\activate
```

### Instale as dependências

```bash
pip install -r requirements.txt
```

### Execute as migrações

```bash
python manage.py migrate
```

### Inicie o servidor

```bash
python manage.py runserver
```
